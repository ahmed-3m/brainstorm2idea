### 1. Executive Summary & Problem
Token-budgeted text chunker and outline builder for large markdown documents

### 2. Goals & Success Metrics
- **Goal**: Split large markdown documents into semantic chunks preserving heading boundaries
- **Goal**: Generate hierarchical table-of-contents outline with token counts per section

### 3. Non-Goals (Strictly Out of Scope)
The following are deliberately excluded from this prototype milestone to maintain velocity:
- ⛔ **Non-Goal**: Direct LLM API calls or vector embeddings
- ⛔ **Non-Goal**: PDF/DOCX binary document parsing

### 4. Functional Requirements & Flows
1. **Flow 1**: parseOutline(markdown: string): DocumentOutline
2. **Flow 2**: chunkByBudget(markdown: string, maxTokens: number): MarkdownChunk[]

### 5. Technical Architecture (LIBRARY)
- **Template Archetype**: `library`
- **Data & State**: Keep in-memory or single local file (JSON/SQLite). No external database clusters or cloud infrastructure for prototype.
- **Dependencies**: Keep runtime dependencies minimal or zero.

### 6. Assumptions & Risks
- ⚠️ ASSUMPTION: Rough 4 characters per token estimate suffices for chunking boundaries

### 7. Implementation Notes
- ℹ️ Zero dependencies; standard Node.js library for agent context management
